5 of 5 guides
The game will not start or closes straight awayYou click Play, nothing happens, or the game closes after the logo.
  1. Restart the PC and try again. Close other programs first.
  2. If you play through Steam: open Library, right-click the game > Properties > Installed Files > Verify integrity of game files. Wait until it finishes.
  3. Right-click the game or its shortcut > Properties > Compatibility > tick Run this program as an administrator.
  4. Update the graphics driver: right-click Start > Device Manager > Display adapters > right-click your graphics card > Update driver. Or download the latest driver from the maker's website (NVIDIA, AMD or Intel).
  5. Install Windows updates: Settings > Windows Update > Check for updates.
  6. Check free space on C:. Games need room for updates and temporary files.
  7. Temporarily turn off any overlay or antivirus that blocks the game, then try again. Turn protection back on after the test.
  8. If it still fails, send us the error message and your PC model.
The game lags or the frame rate is lowPlayers stutter, the picture freezes, or the replay is slow.
  1. Close browsers and other programs. Press Ctrl + Shift + Esc and check that Task Manager shows free memory and low disk use.
  2. Plug the laptop into power. Then choose a performance power plan: Settings > System > Power & battery > Power mode > Best performance.
  3. In the game's settings lower the resolution, shadows and effects. Turn off anything marked high or ultra.
  4. Update the graphics driver (see the first guide).
  5. Turn on Game Mode: Settings > Gaming > Game Mode.
  6. Check the temperature. If the laptop is very hot, clean the vents and use it on a hard surface.
  7. If the game is on a hard disk (HDD), move it to an SSD if you have one. An SSD upgrade and more RAM help older PCs most.
The controller is not detectedThe game ignores your gamepad, or only some buttons work.
  1. Unplug the controller, plug it into another USB port, and try again. Try a different cable.
  2. For Bluetooth controllers, remove the controller in Settings > Bluetooth & devices, then pair it again.
  3. Check that Windows sees it: search Set up USB game controllers, select the controller and choose Properties to test the buttons.
  4. If you play through Steam: Steam > Settings > Controller, and turn on the controller type you use (for example PlayStation or Xbox).
  5. Close the game, connect the controller first, then start the game.
  6. In the game's controller settings, check that the controller is chosen as the input device.
Patch or squad update does not show in the gameThe old teams, kits or faces still appear, or the game crashes after a patch.
  1. Check that the patch was made for your game version. A patch for a different version will not load.
  2. Close the game fully, including Steam, then install the patch again by following its instructions.
  3. Follow the patch's own switch-on step. Some patches need you to pick a patch option in the game's settings or launcher.
  4. If the game crashes after the patch, remove the patch files and verify the game files (see the first guide).
  5. Do not install two patches on top of each other unless the patch says it is safe.
  6. Make sure a game update did not overwrite the patch. After an update you may need to install the patch again.

Patches are made by community creators. Download them only from the creator's own page, and scan the files before you open them.

The game update is stuck or the download is slowThe progress bar does not move, or the download fails.
  1. Check that you have internet by opening a website. Large game updates need a steady connection and enough data.
  2. Check free space on C: or the drive where the game is installed.
  3. Pause the download, wait a minute, then resume it.
  4. Restart Steam and the PC.
  5. In Steam open Settings > Downloads, and click Clear Download Cache. You will sign in again afterwards.
  6. If the download is stuck, set the download region to a nearby server in the same Downloads settings.
  7. If it still fails, bring the PC to us and we will install the update for you.
